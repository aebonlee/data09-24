사진 불러오기

사진을 여러 장 골라 주세요(JPEG·아이폰 HEIC). 찍은 날짜와 위치(EXIF)를 읽어 날짜별로 묶고, 가까운 도시 이름을 붙여요. 사진 원본은 올리거나 복사하지 않고, 작은 미리보기만 이 브라우저에 저장합니다.

아이폰 사진(HEIC)도 그대로 넣을 수 있어요. 날짜·위치는 바로 읽고, 미리보기는 사파리에서는 바로, 크롬·엣지에서는 변환기(약 1.3MB)를 처음 한 번 불러와 만들어요. 아이폰에서 고를 때 위치가 빠지면 사진 고르기 화면 위쪽 「옵션」에서 「위치」를 켜 주세요.

날짜별 기록과 앨범

동선 지도

핀을 누르거나 「이전·다음 장소」로 여행을 따라가 보세요. 장소 이름은 가까운 도시 이름(GeoNames, 인터넷 없이)이고, 설정에서 외부 지도 API 를 켜면 더 자세한 이름을 받을 수 있어요. 선은 같은 날 사진을 찍은 순서대로 이은 직선이라 실제 이동 경로(도로)와는 다를 수 있어요. 지도는 간략한 세계 지도(1:110m)라 해안선이 거칠게 보입니다.

합계

지출 내역

함께 간 사람

나눠 낸 여행이면 함께 간 사람을 더해 주세요. 지출마다 낸 사람과 나눌 사람을 고르면, 누가 누구에게 얼마를 보내면 되는지 계산해 드려요.

처음 더한 사람이 지출의 기본 「낸 사람」이에요. 이름은 가명이나 별명으로 적어도 돼요.

누가 누구에게

내역별 정산

지출마다 낸 사람과 나눌 사람을 바로 고칠 수 있어요. 금액은 원 단위로 나누고, 나누어떨어지지 않는 1원은 앞사람부터 더해요.

요약 카드

여행 이름·기간·나라·사진 수·이동 거리·경비와 동선을 한 장에 담아요. SNS 나 메신저로 보내기 좋게 PNG 로 내려받습니다.

「여행기 인쇄」는 날짜별 일기·사진·지도·경비를 한 문서로 모아 인쇄 창을 엽니다. 인쇄 창에서 「PDF로 저장」을 고르면 PDF 가 됩니다.

AI 여행 리포트

여행 전체 기록으로 「추억 요약」 요청문을 만들어요. 받은 답을 붙여 넣으면 인쇄용 여행기 맨 앞에 들어갑니다.

백업과 설정

자동 모드 — 내 OpenAI 키 (선택)

키를 넣으면 「내 키로 바로 쓰기」 단추가 생겨요. 키는 이 브라우저에만 저장되고 백업 파일에도 들어가지 않아요. 사용 요금은 키 주인에게 청구됩니다. 보내는 것은 요청문 글자뿐이고 사진은 보내지 않아요.

장소 이름 — 외부 지도 API (선택, 기본 꺼짐)

꺼 두면 인터넷 없이 가까운 도시 이름(GeoNames)만 붙여요. 켜면 「동선 지도」에서 단추를 누를 때 장소마다 좌표(위도·경도)만 고른 지도 회사로 보내 동네·명소 이름을 받아 와요. 사진은 보내지 않아요. 키는 본인 것을 쓰고(요금은 키 주인 부담), 이 브라우저에만 저장되며 백업 파일에도 들어가지 않아요.
