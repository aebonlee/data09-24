## 결정과 이유

- **사진은 밖으로 보내지 않는다.** 원본은 `File.arrayBuffer()` 로 EXIF 만 읽고, 긴 변 480px 미리보기만 IndexedDB 에 둡니다. localStorage(5MB 안팎)에는 사진을 넣지 않았습니다 — 10장만 넣어도 가득 찹니다. 백업 JSON 에는 미리보기를 넣을지 고를 수 있습니다.
- **EXIF 파서를 직접 만들었다.** 필요한 태그가 몇 개(DateTimeOriginal·OffsetTimeOriginal·GPS 위경도·Orientation)뿐이라 라이브러리를 들이는 것보다 160줄 남짓한 파서가 가볍고 검사하기 쉽습니다. 검증용 사진도 **파서와 따로 만든 쓰기 코드**(`scripts/make-samples.mjs`)로 EXIF 를 넣어, 같은 코드로 쓰고 읽는 순환 검증이 되지 않게 했습니다. 만든 파일은 Pillow 로도 읽어 GPS·시각이 같은 것을 한 번 대조했습니다.
- **날짜는 카메라 현지 시각 그대로.** EXIF 시각에는 보통 시간대가 없고, 여행 기록에서 필요한 것은 「그곳에서의 날짜」라 변환하지 않습니다. EXIF 가 없으면 파일 수정 시각으로 짐작하되, **그 날짜가 여행 기간 밖이면 「날짜를 확인할 사진」으로 보냅니다.** 헤드리스 검사에서 EXIF 없는 합성 사진이 오늘 날짜(파일을 만든 날)로 묶여 여행과 무관한 9월 29일 기록이 생기는 것을 보고 넣은 규칙입니다(메신저로 받은 사진이 이렇게 됩니다).
- **지도는 오프라인 SVG.** 지도 타일은 외부 서버·키가 필요하고 file:// 로 열 때도 막힐 수 있어, Natural Earth 1:110m 나라 경계만 넣어 직접 그렸습니다. 도시 단위로 확대하면 해안선이 거칠지만(간사이 공항이 「바다」에 찍히지 않고 육지 안으로 보임) 핀 위치는 사진 좌표 그대로입니다. 날짜변경선을 넘는 러시아·피지는 경도를 이어 붙였고, 남극은 뺐습니다.
- **좌표 → 나라는 세 겹.** ① 지도에 모양이 없는 작은 나라(싱가포르·홍콩·마카오·괌·사이판 등 12곳)는 중심·반경으로 먼저 ② 나라 경계 안(짝수 교차 규칙) ③ 해안선이 거칠어 바다로 빠진 좌표(제주 등)는 1도 안의 가장 가까운 경계. 망망대해는 「없음」.
- **동선은 「실제로 다닌 순서」만.** 원문의 경로 추천·최적화는 실제 이동 시간이 필요해 2단계로 두었고, 1단계는 찍은 시각 순으로 잇고 직선거리만 보여 줍니다. 30m 안에서 연달아 찍은 사진은 한 곳으로 합칩니다.
- **경비는 항목마다 반올림.** `Math.round(금액×100) × 환율 / 100` 을 원 단위로 반올림한 뒤 더합니다(12.5달러 × 1385.5 = 17,318.75 → 17,319원). 합계를 나중에 반올림하면 날짜별·분류별 합이 전체 합과 1~2원 어긋나기 때문입니다. 환율은 실시간으로 가져오지 않고 사용자가 적습니다(요청대로). 환율이 없는 통화는 합계에서 빼고 「환율 없는 USD 1건 제외」처럼 알립니다.
- **장소 이름은 자동으로 붙이지 않는다.** 좌표 → 장소 이름(역지오코딩)은 외부 API 가 필요해, 기록의 장소 칸에는 나라 이름만 미리 채우고 사람이 고치게 했습니다(기획서 10장 질문 3).
- **일기 도우미는 「지어내지 말 것」.** 요청문에 날짜·여행 며칠째·장소·그날 들른 곳·사진 장수와 시간대·이동 거리·키워드를 넣고, 메모에 없는 가게 이름·가격·날씨·동행을 만들지 말라는 조건을 붙였습니다. 답의 「제목:」 줄을 떼어 기록 제목으로 씁니다. 자동 모드는 본인 OpenAI 키(localStorage, 백업 제외)로 요청문 글자만 보냅니다.
- **요약 카드는 캔버스로 직접 그림.** 지도도 같은 투영 함수의 SVG 경로를 `Path2D` 로 그려, 화면 지도와 카드 지도가 같은 모양입니다. 사진 썸네일은 카드에 넣지 않았습니다(file:// 에서 캔버스가 오염되어 PNG 저장이 막히는 경우를 피함).
- **여행기 PDF 는 인쇄 스타일로.** 라이브러리 없이 인쇄 전용 영역(`#printView`)을 만들고 `window.print()` — 인쇄 창의 「PDF로 저장」을 씁니다.
- **휴대폰 화면 손질(헤드리스 검사에서 발견).** ① 360px 에서 지도 SVG 를 960 폭으로 그려 줄이니 핀이 3px 이 되어, 지도를 **보이는 폭 그대로** 그리게 바꿨습니다. ② 가까운 곳의 핀이 겹쳐 누를 수 없는 경우가 있어(Day 1 도톤보리 · Day 2 오사카성), 「날짜별 동선」에 장소마다 시각 단추를 두어 거기서도 고를 수 있게 했습니다. ③ 고정된 머리가 휴대폰 화면의 1/4 을 가려 1024px 이상에서만 고정합니다. ④ 외화 12.50달러가 「13 USD」로 반올림되어 보이던 것을 소수 둘째 자리까지 표시하게 고쳤습니다.
- **DB 는 준비만.** 1단계 앱은 DB 를 쓰지 않습니다. 계정·공동 기록(2단계)을 대비해 스키마와 검증 하네스를 두었고, 기록을 지우면 사진은 남기고 연결만 푸는 규칙을 `on delete set null (entry_id)`(열 지정, PostgreSQL 15+)로 걸었습니다. 복합 외래키 전체를 NULL 로 만드는 기본 SET NULL 은 `owner_id not null` 과 부딪히기 때문입니다.
