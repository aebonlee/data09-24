## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data09-24/**

처음 열면 빈 화면입니다. 「예시 여행 불러오기」로 가상의 「간사이 3박 4일」(합성 사진 10장·일기·경비)과 지난 여행 2개를 불러올 수 있습니다. 사진·위치·환율은 모두 가상입니다.
직접 해 보려면 이 저장소의 `samples/` 에 있는 합성 JPEG 10장을 내려받아 「기록·사진 → 사진 고르기」로 넣어 보세요(가짜 EXIF 날짜·GPS 가 들어 있습니다).

내 PC에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN·지도 서버를 부르지 않아 인터넷 없이도 됩니다(자동 모드 AI 만 인터넷 필요).

| 화면 | 하는 일 |
|---|---|
| 여행 | 이름·기간(몇 박 며칠)·나라·도시·메모, 이 여행 통계. **방문한 나라와 도시** — 모든 여행을 모은 세계 지도(방문 나라 칠하기, 사진 위치 점), 내 여행 목록 |
| 기록·사진 | 사진 여러 장 고르기 → EXIF 날짜·GPS 읽기 → 날짜별 앨범. 위치로 나라 자동 추가, 기간 자동 채우기, 같은 사진 건너뛰기. 「사진으로 날짜별 기록 만들기」, 날짜를 확인할 사진(EXIF 없음·파일 날짜가 기간 밖) 날짜 정하기. 기록 쓰기·고치기, **일기 도우미**(요청문 → ChatGPT·Copilot → 붙여넣기, 선택: 내 키로 바로 쓰기) |
| 동선 지도 | 날짜별 색 동선 선, 번호 핀, 사진 썸네일, 축척 막대. 여행 전체 / Day N 보기, 핀을 누르면 사진·시각·좌표·그날 기록. 날짜별 장소 수·직선거리 |
| 경비 | 날짜·금액·통화(15종)·분류·메모. 환율은 직접 입력(1 JPY = 9.12원 식). 여행·날짜별·분류별 합계, 환율 없는 통화는 합계에서 빼고 알림 |
| 요약·내보내기 | 요약 카드 PNG(1080×1080), 여행기 인쇄/PDF, AI 여행 리포트(요청문 → 붙여넣기), JSON 백업·가져오기(사진 미리보기 포함 선택), OpenAI 키 설정 |

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음) — EXIF 읽기(합성 JPEG 10장), 날짜 묶기, 동선 순서, 경비 환산, 나라 판정, 프롬프트, 백업 검사
- DB 스크립트 검증: `./scripts/sqltest/run.sh` (로컬 PostgreSQL 필요)
- 합성 사진 다시 만들기: `scripts/make-samples.mjs`, 지도 자료 다시 만들기: `scripts/build-world.mjs` (각 파일 첫 줄에 방법)

## 1단계 구현 범위

| 원문 기능 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 사진 기반 위치·일자 자동 태깅 | 완료 | 직접 만든 EXIF 파서(외부 라이브러리 없음), 날짜별 묶기, 좌표 → 나라. 장소 이름 자동은 2단계 |
| 텍스트 기반 일기 생성 (LLM) | 완료 | 반자동 요청문 + 선택 자동 모드(본인 OpenAI 키). 음성 입력은 2단계 |
| 동선 시각화 · 핀과 썸네일 | 완료 | 오프라인 SVG 지도(Natural Earth 1:110m) |
| 여행 지도 · 방문한 국가와 도시 | 완료 | 모든 여행 합산 세계 지도 |
| 여행 앨범 · 여행별 기록 · 경비 | 완료 | 날짜별 앨범, 직접 입력 환율로 원 환산 |
| 요약 카드 · 여행기 PDF · AI 여행 리포트 | 완료 | PNG 카드, 인쇄용 여행기 1종, 리포트 요청문 |
| Vision AI 분류 · 경로 최적화 · 취향 분석 · 추천 | 2단계 | 사진을 외부로 보내야 하거나 외부 자료(이동 시간·장소 DB)·여러 여행의 기록이 필요 — [기획서 5장](docs/01_프로젝트_기획서.md) |
| 계정 · 공동 여행 기록 · 링크 공유 · 여행 전 계획 | 2단계 | DB 스키마·검증 하네스는 준비됨 |

개인정보: 사진 원본은 올리거나 복사하지 않습니다. 미리보기만 이 브라우저(IndexedDB)에 저장됩니다. `samples/` 의 사진은 모두 합성 이미지이며 실제 사진이 아닙니다.
