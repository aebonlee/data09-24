# data09-24 · JOURNAL

사진(JPEG·아이폰 HEIC)을 고르면 찍은 날짜와 위치(EXIF)로 여행을 날짜별로 묶고, 도시 이름·동선 지도·방문 국가·경비와 정산·일기 도우미·요약 카드까지 한곳에 담는 여행 기록일지 — 사진은 이 브라우저 밖으로 나가지 않습니다

| 항목 | 내용 |
|---|---|
| 제출자 | 김세이 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-09-29) + 수강생 답변 반영 (2026-09-30: HEIC·도시 이름·외부 지도 API·USD/JPY/EUR·정산 탭·앨범·대시보드) — https://aebonlee.github.io/data09-24/ |
| 다음 개발 | 2단계 — 음성 입력, 경로 추천, 취향 분석·추천, 계정·공동 여행 기록 (Vision AI 분류는 수강생 답으로 제외) |

> data09-12(외자재 운영관리 Agent)와 같은 수강생의 두 번째 과제입니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data09-24/**

처음 열면 빈 화면입니다. 「예시 여행 불러오기」로 가상의 「간사이 3박 4일」(합성 사진 10장·일기·경비)과 지난 여행 2개(정산 예시 「다낭 가족여행」 포함)를 불러올 수 있습니다. 사진·위치·환율·사람 이름은 모두 가상입니다.
직접 해 보려면 이 저장소의 `samples/` 에 있는 합성 JPEG 10장이나 `samples/heic/` 의 HEIC 3장을 내려받아 「기록·사진 → 사진 고르기」로 넣어 보세요(가짜 EXIF 날짜·GPS 가 들어 있습니다).

내 PC에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN·지도 타일을 부르지 않아 인터넷 없이도 됩니다(자동 모드 AI 와, 켰을 때의 외부 지도 API 만 인터넷 필요).

| 화면 | 하는 일 |
|---|---|
| 여행 | 이름·기간(몇 박 며칠)·나라·도시·메모, 이 여행 통계. **방문한 나라와 도시** — 모든 여행을 모은 세계 지도(방문 나라 칠하기, 사진 위치 점), 내 여행 목록 |
| 기록·사진 | 사진 여러 장 고르기(JPEG·**아이폰 HEIC**) → EXIF 날짜·GPS 읽기 → 날짜별 앨범. 위치로 나라·**가까운 도시** 자동 추가, 기간 자동 채우기, 같은 사진 건너뛰기. 「사진으로 날짜별 기록 만들기」(장소 칸에 그날 도시들), 날짜를 확인할 사진 날짜 정하기. 기록 쓰기·고치기, **일기 도우미**. 보기 전환 **「사진 크게 보기」** — 날짜별 큰 사진 격자, 누르면 크게(←·→ 넘기기, Esc 닫기) |
| 동선 지도 | 날짜별 색 동선 선, 번호 핀, 사진 썸네일, 축척 막대. 여행 전체 / Day N 보기, **「이전·다음 장소」로 따라가기**, 핀을 누르면 사진·시각·도시·그날 기록. 날짜별 장소(시각·도시) 단추·직선거리. 선택: 외부 지도 API 로 동네·명소 이름 받기 |
| 경비 | **경비 한눈에**(총액·하루 평균·가장 많이 쓴 곳·건수·분류 비율, 보기 통화 원·USD·JPY·EUR). 날짜·금액·통화(15종)·분류·메모, 함께 간 사람이 있으면 낸 사람·나눌 사람. 환율은 직접 입력(1 JPY = 9.12원 식, USD·JPY·EUR 칸은 늘 있음). 여행·날짜별·분류별 합계 |
| 정산 | 함께 간 사람(가명 가능), 사람별 낸 돈·부담할 몫·차액, **누가 누구에게 얼마 — 송금 횟수 최소**, 내역별로 낸 사람·나눌 사람을 그 자리에서 고치기(1인당 몫 표시) |
| 요약·내보내기 | 요약 카드 PNG(1080×1080), 여행기 인쇄/PDF(정산 표 포함), AI 여행 리포트(요청문 → 붙여넣기), JSON 백업·가져오기(사진 미리보기 포함 선택), OpenAI 키 설정, **외부 지도 API 설정(Google·카카오, 본인 키, 기본 꺼짐)** |

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음, 44개) — EXIF 읽기(합성 JPEG 10장·HEIC 3장·직접 만든 HEIF), 날짜 묶기, 동선 순서, 경비 환산, 나라 판정, 도시 이름, 표시 통화, 정산(최소 송금), 지도 API 답 읽기, 프롬프트, 백업 검사
- DB 스크립트 검증: `./scripts/sqltest/run.sh` (로컬 PostgreSQL 필요)
- 합성 사진 다시 만들기: `scripts/make-samples.mjs`(HEIC 는 macOS 에서 `sips -s format heic samples/<파일>.jpg --out samples/heic/<파일>.heic`), 지도 자료: `scripts/build-world.mjs`, 도시 자료: `scripts/build-cities.mjs` (각 파일 첫 줄에 방법)

## 1단계 구현 범위

| 원문 기능 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 사진 기반 위치·일자 자동 태깅 | 완료 | 직접 만든 EXIF 파서(JPEG·HEIC, 외부 라이브러리 없음), 날짜별 묶기, 좌표 → 나라·도시(GeoNames, 오프라인). 동네·명소 이름은 선택(외부 지도 API) |
| 텍스트 기반 일기 생성 (LLM) | 완료 | 반자동 요청문 + 선택 자동 모드(본인 OpenAI 키). 음성 입력은 2단계 |
| 동선 시각화 · 핀과 썸네일 | 완료 | 오프라인 SVG 지도(Natural Earth 1:110m) |
| 여행 지도 · 방문한 국가와 도시 | 완료 | 모든 여행 합산 세계 지도 |
| 여행 앨범 · 여행별 기록 · 경비 | 완료 | 날짜별 앨범 + 사진 크게 보기, 직접 입력 환율로 원 환산, USD·JPY·EUR 보기, 경비 한눈에 |
| 경비 정산 (내역별) | 완료 (2026-09-30) | 낸 사람·나눌 사람, 사람별 차액, 최소 송금 |
| 요약 카드 · 여행기 PDF · AI 여행 리포트 | 완료 | PNG 카드, 인쇄용 여행기 1종, 리포트 요청문 |
| 경로 최적화 · 취향 분석 · 추천 | 2단계 | 외부 자료(이동 시간·장소 DB)·여러 여행의 기록이 필요 — [기획서 5장](docs/01_프로젝트_기획서.md). Vision AI 분류는 수강생 답으로 제외 |
| 계정 · 공동 여행 기록 · 링크 공유 · 여행 전 계획 | 2단계 | DB 스키마·검증 하네스는 준비됨 |

개인정보: 사진 원본은 올리거나 복사하지 않습니다. 미리보기만 이 브라우저(IndexedDB)에 저장됩니다. `samples/` 의 사진은 모두 합성 이미지이며 실제 사진이 아닙니다.
